# ERP AI Copilot Frontend

Dự kiến triển khai Next.js 14+ (App Router), TypeScript, và Tailwind CSS:
- **Home / AI Copilot:** Hero chat input, KPI demo, gợi ý câu hỏi
- **ERP Dashboard:** Quản lý Khách hàng, Sản phẩm, Tồn kho, Đơn hàng
- **Document Review:** Giao diện upload tài liệu, review trường dữ liệu trích xuất
- **Approval Inbox:** Hộp thư phê duyệt hành động đơn hàng draft
